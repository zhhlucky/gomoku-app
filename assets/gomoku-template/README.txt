1. 解压整个文件夹。 / Extract the complete folder.
2. 双击 Start-Luozi-Review.cmd。 / Double-click Start-Luozi-Review.cmd.
3. 首次运行等待安装完成，页面会打开 http://localhost:3015。 / Wait for first-time setup; the page opens at http://localhost:3015.
4. 使用时保持两个 PV5 命令窗口开启。 / Keep both PV5 command windows open while using the app.

应用支持先后手选择、Rapfi 自动应手、棋盘半透明五手提示、最佳路线面板、SGF/RENJU 导入和全局扣分复盘。
The app supports side selection, automatic Rapfi replies, five-ply translucent hints, a best-line panel, SGF/RENJU import, and full-game score-loss review.
